# drake-logger-site

Published dashboard for drake-logger: archived Open-Meteo wave and wind forecasts for the
Ushuaia - Drake Passage - Antarctic Peninsula route. Generated automatically; do not edit.

Weather data by [Open-Meteo.com](https://open-meteo.com/), licensed
